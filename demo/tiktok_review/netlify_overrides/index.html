What Shorts Media does

A clear path from prepared content to an authorized TikTok account.

Shorts Media provides the workflow around account authorization, content preparation, publishing settings, and transmission to TikTok through supported TikTok developer products.

1

Connect

The user authorizes a TikTok account through TikTok's authorization flow. Shorts Media does not ask users to share their TikTok password with Shorts Media.

2

Prepare

The user works with video content and the information associated with a post, subject to the options available for the connected account.

3

Publish

Authorized publishing requests are transmitted using TikTok's supported developer interfaces and are subject to TikTok's platform rules and availability.

TikTok integration

Built around user authorization and supported platform interfaces.

Login Kit

Shorts Media uses TikTok's authorization experience to request only the access needed for configured features. Authorization is granted by the TikTok user and can be revoked by the user.

Content Posting API

Shorts Media uses TikTok's Content Posting API for supported publishing functionality on accounts that have authorized the required access. TikTok controls the availability and rules of its API.

Common questions

Plain-language answers.

Does Shorts Media need my TikTok password?

No. TikTok account authorization occurs through TikTok's authorization process rather than by giving a TikTok password to Shorts Media.

Can I revoke access?

Yes. TikTok authorization can be revoked through TikTok's account controls. See Data & privacy controls for additional information.

Who is responsible for uploaded content?

The user is responsible for ensuring that they own or have permission to publish the content they choose to use with Shorts Media.

How do I contact Shorts Media?

Use the Shorts Media support form for general, account-authorization, privacy, or data requests.
