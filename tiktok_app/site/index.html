What Shorts Media does

Three steps from a release asset to a TikTok post.

Many creators and teams build their videos automatically and publish the finished files as GitHub release assets. Shorts Media turns that folder of files into a library you can post from, without moving the files anywhere.

1

Connect TikTok

You authorize Shorts Media on TikTok's own authorization screen. Shorts Media never asks for your TikTok password, and you can revoke the access in TikTok at any time.

2

Add your sources

Enter a public GitHub repository and every video attached to its releases appears in your library, newest first. Or add a direct link to a single video file. Check a repository again whenever a new release lands.

3

Post when you are ready

Open a video, play the preview, write the caption, choose who can view it and the interaction and disclosure settings, then press Post. Shorts Media sends the video to TikTok in parts and shows you when it is live.

TikTok integration

Built around user authorization and supported platform interfaces.

Login Kit

Shorts Media uses TikTok's authorization experience to request only the access needed for configured features. Authorization is granted by the TikTok user and can be revoked by the user.

Content Posting API

Shorts Media uses TikTok's Content Posting API to post a video directly to your account with the settings you chose, or to send it to your TikTok inbox as a draft. TikTok controls the availability and rules of its API.

Common questions

Plain-language answers.

Does Shorts Media need my TikTok password?

No. TikTok account authorization occurs through TikTok's authorization process rather than by giving a TikTok password to Shorts Media.

Can I revoke access?

Yes. TikTok authorization can be revoked through TikTok's account controls. See Data & privacy controls for additional information.

Where do my videos have to be?

Attached to a release of a public GitHub repository, or at any direct https link to an .mp4, .mov or .webm file. Shorts Media reads a file only when you post it; it does not keep copies.

Who is responsible for uploaded content?

You are: you must own or have permission to publish the videos you choose to post with Shorts Media.

How do I contact Shorts Media?

Use the Shorts Media support form for general, account-authorization, privacy, or data requests.
